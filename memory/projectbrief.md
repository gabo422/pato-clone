# Project Brief — Pato-Clone

## Qué es
Un clon web (Three.js + HTML) del juego *Ace Online* (AO), sola página `index.html`, diseñado para ser igual de fiel al AO original en mecánicas de combate (mobs, boss, gears, armas).

## Alcance / objetivo
Recrear lo más fielmente posible el comportamiento del AO:
- 4 gears jugables (Rayo, Muro, Trueno, Viento).
- Armas estándar y avanzada por gear, con homing/turn diferenciados.
- Mobs y boss con IA de movimiento/ataque fiel al AO (no orbitan, distancias de ataque, media vuelta, etc.).
- Publicado en GitHub Pages para que Gabriel juegue.

## Para quién
Gabriel (gabo422), ex-jugador de AO, que quiere jugar y reportar bugs en lenguaje natural. No es programador.

## Cómo se entrega
Commits en español, push a `gabo422/pato-clone` (main), GitHub Pages auto-genera. Gabriel espera 1-2 min y hace Ctrl+F5.
